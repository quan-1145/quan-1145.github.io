计算机基础问答 20 题

1. BIOS一般集成在哪种芯片中？简述BIOS的基本功能。

  • 芯片：BIOS（基本输入输出系统）一般集成在主板上的ROM芯片（具体为Flash ROM或EEPROM）中。
  • 基本功能：
    1. 开机自检（POST）：检测CPU、内存、键盘等关键硬件是否存在并正常工作。
    2. 硬件初始化：对主板芯片组、显卡、硬盘等设备进行初始化和参数设置。
    3. 引导操作系统：根据CMOS中设定的启动顺序，从硬盘、光盘或USB设备加载操作系统引导程序。
    4. 提供基本I/O服务：为操作系统提供底层硬件访问的例程（如键盘输入、屏幕显示）。

2. CPU内部主要有哪几部分组成？简述每部分的基本功能。

CPU主要由以下几部分组成：

  • 算术逻辑单元（ALU）：负责执行所有算术运算（加、减、乘、除）和逻辑运算（与、或、非、异或）。
  • 控制单元（CU）：负责从内存取指令，对指令进行译码，并产生控制信号，协调各部件完成指令规定的操作。
  • 寄存器组（Registers）：CPU内部高速存储单元，用于临时暂存指令、数据和内存地址，减少CPU访问内存的频率。
  • 高速缓存（Cache）：位于CPU内部或封装附近，用于缓存频繁使用的数据和指令，弥合CPU与主存之间的速度差异。

3. 简述内存的基本功能。

内存（主存）的基本功能是临时存储正在运行的程序代码和程序处理的数据。CPU直接从内存中读取指令和数据，运算结果也暂存在内存中。其特点是读写速度快（相对于外存），但断电后数据会丢失（易失性）。

4. 简述显卡的基本功能。

显卡（图形处理卡）的基本功能是将CPU送来的图像数据转换成显示器可以显示的模拟或数字信号，控制显示器的正确显示。现代显卡还包含GPU（图形处理器），能够并行处理大量图形渲染计算（如3D场景、纹理映射），大幅减轻CPU的负担。

5. 图灵模型最重要的贡献是什么？

图灵模型（图灵机）最重要的贡献是提出了通用计算机的数学逻辑模型，证明了任何可计算的问题都可以用一台具有无限存储带的简单机器来求解。它奠定了“存储程序”概念的理论基础，是现代计算机体系结构（冯·诺依曼架构）的先驱，并定义了计算的极限（可判定性理论）。

7. 十进制正数转二进制的UML图与正确性证明

UML活动图（文本描述流程）：

  1. 开始
  2. 将数分为整数部分 (N) 和小数部分 (F)。
  3. 整数部分循环（直到 (N=0)）：
    • 将 (N) 除以 2，记录余数（0或1）。
    • 更新 (N = \lfloor N/2 \rfloor)。
    • 将余数依次压入栈（最后出栈即为二进制整数高位到低位）。
  4. 小数部分循环（直到 (F=0) 或达到精度）：
    • 将 (F) 乘以 2，记录整数位（0或1）。
    • 更新 (F = F \times 2 - \text{整数位})。
    • 顺序输出整数位（即为二进制小数位）。
  5. 合并整数部分和小数部分，结束。

正确性证明：
设十进制正数 (X)，其二进制展开为 (X = \sum_{i=-\infty}^{n} d_i 2^i)，其中 (d_i \in {0,1})。

  • 整数部分：对 (X) 取整，除以2。由于 (d_0) 决定奇偶性，(X \mod 2 = d_0)，余数即最低位。反复除以2并取余，每次分离出 (d_0, d_1, …)，根据多项式展开的唯一性，此过程穷举了所有系数。
  • 小数部分：乘以2，得到 (2F = d_{-1} + \sum_{i=-\infty}^{-2} d_i 2^{i+1})，整数部分恰好是 (d_{-1})。反复乘2取整，依次分离出 (d_{-1}, d_{-2}, …)。根据基展开的唯一性，算法收敛于正确值。

9. 证明正整数N所需二进制位数

设二进制位数为 (K)，则能表示的最大值为 (2^K - 1)，最小值为 (2^{K-1})（K位二进制中，最高位为1，其余为0）。
要表示 (N)，必须满足：
[
2^{K-1} \le N \le 2^K - 1
]
取以2为底的对数：
[
K-1 \le \log_2 N < K
]
因为 (\log_2 N < K)，且 (\log_2 N \ge K-1)，所以小于等于 (\log_2 N) 的最大整数为 (K-1)，即：
[
\lfloor \log_2 N \rfloor = K-1
]
移项得：
[
K = \lfloor \log_2 N \rfloor + 1
]
得证。

11. 多媒体数据类型及存储形式

多媒体数据类型包含：文本（Text）、图形/图像（Image/Graphics）、音频（Audio）、视频（Video）和动画（Animation）。
它们在计算机中都以二进制位模式（0和1的序列） 的形式存储，即经过采样、量化、编码（压缩）后转化为数字信号。

12. 什么是位模式？指令和数据都以位模式储存吗？

  • 位模式：指由固定数量的二进制位（0和1）组成的特定排列序列，是计算机内部表示所有信息的基本单位。
  • 储存形式：是的。在冯·诺依曼体系结构中，指令和数据都以二进制位模式存储在内存中。计算机依靠程序计数器（PC）和指令周期的不同阶段（取指 vs 执行）来区分当前读取的是指令还是数据。

14. 8位二进制补码表示法的最小十进制数值

最小值是 -128。
原因：8位补码的表示范围为 (-2^{7} \sim 2^{7}-1)，即 -128 到 127。补码中，最高位（符号位）的权值为 (-2^{7} = -128)。要得到最小数，将最高位设为1（贡献-128），其余所有位设为0，即二进制 ((10000000)_2) 表示 (-128)。若其余位有任何1，数值会变大（如10000001 = -127）。

16. 补码带来减法简便的原因及正确性证明

原因：补码将减法统一为加法运算，因此CPU内部只需设计加法器即可完成加减法，无需独立的减法器硬件。

证明（模 (2^n) 系统下）：
对于 (n) 位补码，模数为 (2^n)。负数 (X) 的补码定义为 ([X]_{\text{补}} = 2^n + X)（当 (X<0) 时，实际为 (2^n - |X|)）。

设要计算 (A - B)，其中 (A, B) 在表示范围内。
因为 (-B) 的补码为 ([-B]{\text{补}} = 2^n - B)（若B>0）。
于是：
[
[A - B]{\text{补}} \equiv 2^n + A - B \pmod{2^n}
]
而：
[
[A]{\text{补}} + [-B]{\text{补}} = (2^n + A) + (2^n - B) = 2^n + (2^n + A - B) \equiv 2^n + A - B \pmod{2^n}
]
两者同余，即补码加法结果正是 (A-B) 的补码。证毕。

18. 程序计数器的功能

程序计数器（PC，Program Counter）是CPU内部的一个寄存器，其功能是存放下一条将要执行的指令在内存中的地址。在顺序执行时，每取出一条指令，PC自动增加（指向下一条指令）；当遇到跳转、循环或子程序调用时，PC会被修改为目标地址，从而控制程序的执行流。

19. RAM和ROM的区别；“随机”的含义

  • 区别：
    • RAM（随机存取存储器）：可读可写，断电后数据丢失（易失性），速度快，用于存储运行中的程序和数据。
    • ROM（只读存储器）：只能读取（通常不能随意写入），断电后数据保留（非易失性），用于存储固件（如BIOS）。
  • “随机”的含义：指存取时间与数据存储的物理位置无关。CPU可以在任意时刻以相同的速度访问任意地址单元，而不必像磁带等顺序介质那样按顺序查找。

20. SRAM 和 DRAM 的优缺点

  • SRAM（静态随机存取存储器）：
    • 优点：速度快（不需要定期刷新），功耗较低（静态电流）。
    • 缺点：集成度低（每个单元需要6个晶体管），成本高，容量小。
  • DRAM（动态随机存取存储器）：
    • 优点：集成度高（每个单元只需1个晶体管和1个电容），成本低，容量大。
    • 缺点：速度较慢（相对SRAM），需要周期性刷新（因电容会漏电），功耗略高。
